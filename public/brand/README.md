Sewiness brand files

- `sewiness-logo.png`    square emblem on a white tile. This is the SOURCE for `npm run icons`,
                          which rebuilds every favicon and app icon in /public.
- `sewiness-mark.png`    the emblem on a transparent background, used inside the app (login, reset pages).
- `sewiness-wordmark.png` the full logo with the name, used on the sign-in page.

To change the logo later, replace these files and run `npm run icons`.
