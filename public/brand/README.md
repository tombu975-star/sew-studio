Sewsiness brand files

- `sewsiness-logo.png`    square emblem on a white tile. This is the SOURCE for `npm run icons`,
                          which rebuilds every favicon and app icon in /public.
- `sewsiness-mark.png`    the emblem on a transparent background, used inside the app (login, reset pages).
- `sewsiness-wordmark.png` the full logo with the name, used on the sign-in page.

To change the logo later, replace these files and run `npm run icons`.

Brand colour: burgundy. The main brand red is #832138 (hover #6C1C2F, sidebar #391019). The logo, icons,
app theme and the platform colour settings all use it. If the logo is ever replaced, run `npm run icons`.

Logo: the artwork is the Burgundy & Gold Atelier logo. Text colours are checked for readability (4.5:1 or better on white and on the page background).
