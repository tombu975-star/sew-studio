    47→## API CONTRACT (backend must implement; views must call these)
    48→═══════════════════════════════════════════════════════════════════
    49→All routes under `src/app/api/`. Return JSON. Dates are ISO strings.
    50→
    51→### Dashboard aggregate
    52→- `GET /api/dashboard` → `{ orders: Order[], payments: Payment[], fittings: Fitting[], tasks: Task[], users: User[], customers: Customer[], settings: Settings, styleConcepts: StyleConcept[] }`
    53→  (orders include customer + assignedStaff; payments/fittings/tasks as flat arrays with orderId)
    54→
    55→### Customers
    56→- `GET /api/customers` → `Customer[]` (each with computed `_orderCount?: number`)
    57→- `POST /api/customers` body: Customer fields → `Customer`
    58→- `GET /api/customers/[id]` → `{ customer: Customer, orders: Order[], measurements: MeasurementSet[], feedback: CustomerFeedback[], styleConcepts: StyleConcept[] }`
    59→- `PATCH /api/customers/[id]` body: partial Customer → `Customer`
    60→
    61→### Orders
    62→- `GET /api/orders` → `Order[]` (include customer, assignedStaff, payments[], fittings[])
    63→- `POST /api/orders` body: { customerId, garmentDesign, orderDate, deliveryDate?, status?, assignedStaffId?, sellingPrice?, fabricCost?, labourCost?, notes?, priority? } → `Order`
    64→- `GET /api/orders/[id]` → `Order` (include customer, assignedStaff, payments[], fittings[], tasks[])
    65→- `PATCH /api/orders/[id]` body: partial Order (esp. status) → `Order`
    66→- `POST /api/orders/[id]/payments` body: { amount, method?, note? } → `Payment`
    67→- `POST /api/orders/[id]/fittings` body: { date, status?, notes? } → `Fitting`
    68→- `PATCH /api/fittings/[id]` body: partial Fitting → `Fitting`
    69→
    70→### Tasks
    71→- `GET /api/tasks` → `Task[]` (include order.customer, staff)
    72→- `POST /api/tasks` body: { title, orderId?, staffId?, status?, priority?, dueDate?, notes? } → `Task`
    73→- `PATCH /api/tasks/[id]` body: partial Task → `Task`
    74→
    75→### Measurements
    76→- `GET /api/customers/[id]/measurements` → `MeasurementSet[]`
    77→- `POST /api/measurements` body: MeasurementSet fields → `MeasurementSet`
    78→
    79→### Users / Settings
    80→- `GET /api/users` → `User[]`
    81→- `GET /api/settings` → `Settings` (singleton; create if missing)
    82→- `PATCH /api/settings` body: partial Settings → `Settings`
    83→
    84→### Style Concepts
    85→- `GET /api/style-concepts?customerId=ID` → `StyleConcept[]`
    86→- `POST /api/style-concepts` body: StyleConcept fields → `StyleConcept`
    87→- `PATCH /api/style-concepts/[id]` body: partial (esp. status, rejectionReason, imageUrl) → `StyleConcept`
    88→
    89→### AI endpoints (backend uses z-ai-web-dev-sdk)
    90→- `POST /api/style-assist/generate` body: `{ customerId, request: { garmentType, occasion?, desiredLook?, season?, budget?, fabricAvailable?, colourPreference?, designerDirection? } }`
    91→  → `{ dataConfidence: 'Limited'|'Good'|'Complete', confidenceNote: string, concepts: ConceptDraft[] }`
    92→  ConceptDraft = { conceptName, silhouette?, neckline?, sleeveStyle?, length?, fabric?, colour?, detailing?, embellishment?, whyThisMayWork, fitConsiderations?, matchPercent?, designDirection? }
    93→- `POST /api/style-assist/visualize` body: `{ concept: { conceptName, silhouette, fabric, colour, neckline, sleeveStyle, length, embellishment } }`
    94→  → `{ imageUrl: string }` (uses image generation skill)
    95→- `POST /api/insights/trends` body: `{ orders, payments, customers, fittings }` (summary arrays) → `{ suggestions: string[] }` (3-5 short business insights)
    96→

   650→### Time-ago helper (inline in Community)
   651→```
   652→function timeAgo(iso: string) {
   653→  const d = new Date(iso).getTime();
   654→  const diff = Date.now() - d;
   655→  const m = Math.floor(diff / 60000);
   656→  if (m < 1) return "just now";
   657→  if (m < 60) return `${m}m ago`;
   658→  const h = Math.floor(m / 60);
   659→  if (h < 24) return `${h}h ago`;
   660→  const days = Math.floor(h / 24);
   661→  if (days < 7) return `${days}d ago`;
   662→  return new Date(iso).toLocaleDateString("en-GB", { day: "numeric", month: "short" });
   663→}
   664→```
